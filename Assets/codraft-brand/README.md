# codraft — brand package

The final logo set: the wordmark, the main icon (C), the small icon (B), circle-safe social profile images and a web favicon set ready for the site root.

## What's inside

```
codraft-brand/
├── wordmark/                     wordmark in four colourways — SVG + PNG 1200 / 2400 px wide
├── icon-main/                    main icon C — SVG + PNG 512 / 1024 px
├── icon-small/                   small icon B — SVG + PNG 32 / 64 / 128 px
├── social/                       circle-safe profile images — PNG 400 / 1080 px
├── web/                          favicon set with standard file names
├── codraft-overview-sheet.pdf    every file as a labelled thumbnail (A3 landscape)
├── codraft-overview-sheet.png    same, as one image
└── README.md
```

## Brand colours

| Colour | Hex | RGB | Use |
|---|---|---|---|
| Navy | `#0F1B2D` | 15, 27, 45 | Lettering; dark backgrounds |
| Blue | `#2F6BFF` | 47, 107, 255 | Accents only: the c's segment, the drafting line and the nodes |
| Off-white | `#F6F5F1` | 246, 245, 241 | Light backgrounds; lettering in the reverse version |
| White | `#FFFFFF` | 255, 255, 255 | The mono-white version only |

Contrast (WCAG 2.x): blue on navy **3.84:1** — above the 3:1 minimum for graphics, so the reverse version keeps `#2F6BFF` unchanged. Blue on off-white 4.12:1; navy on off-white 15.8:1.

## Which mark to use

| Mark | Use it for | Size |
|---|---|---|
| **Wordmark** | Anywhere the full name fits: website header, documents, invoices, slides, email signature, signage | At least 20 px tall on screen (about 93 px wide); at least 25 mm wide in print |
| **Main icon — C** | Square placements: app and marketplace icons, avatars, title slides, merch. For circular crops use the `social/` images | 180 px and up |
| **Small icon — B** | Favicons, browser tabs, toolbars, small avatars and inline UI | 16–128 px |

- Below 180 px use **B**; from 180 px up use **C**.
- **Colourways:** primary on white or off-white; reverse on navy or other dark backgrounds; mono-navy or mono-white when only one colour can be printed or shown.
- **Clear space:** keep at least the height of the "c" free on every side of the wordmark. The icon PNGs already include their padding.
- Don't stretch, rotate, outline or add effects to the marks, and don't move the blue to other parts of the letters.

## Notes for developers

- **SVG structure:** outlined paths only, the viewBox cropped tightly to the artwork, no background, and two groups — `.cd-ink` (lettering) and `.cd-accent` (blue details). Recolour with CSS, for example `.cd-ink { fill: currentColor; }` when the SVG is inlined.
- **SVG masters vs PNG icons:** the icon SVGs are cropped to the mark; the PNG icons are square and include padding (10% for C; 1.5 px at 32 px for B).
- **Dark mode:** `web/icon.svg` switches the navy to off-white through `@media (prefers-color-scheme: dark)`, so the favicon stays visible on dark browser tabs. `favicon.ico` is the fallback for browsers that don't support SVG favicons.
- **Apple touch icon:** the mark is scaled to 70% of the tile so the corner nodes sit clear of the rounded corners iOS applies.
- **Social images:** the corner nodes sit inside 84% of the circle's diameter, so Instagram, LinkedIn and Facebook crops never cut them. Upload the 1080 px version.
- **Web setup:** copy the contents of `web/` to the site root and paste `head-snippet.html` into the `<head>` of every page. Change `name` / `short_name` in `site.webmanifest` if the site should show a different name.
- **Content credentials:** files exported from the design workspace may carry a C2PA content-credentials manifest (a `<metadata>` block in SVGs, embedded data in PNG and PDF). It doesn't affect how the files render.
