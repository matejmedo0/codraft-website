# Hosting and services research (2026-10-18)

> **Phase 1 input, not a decision.** These facts were collected while planning so that phase 1 starts informed. The `architect` agent has no web access. At the start of phase 1, the main session re-checks everything marked "to verify", completes the open list, and passes the results (with dates and URLs) into the architecture brief. Decisions are recorded as ADRs 0007 and later.

## Client constraints

- **Budget:** as close to €0/month as possible. A small paid host is fine; the client mentioned Hetzner.
- **Forms and email:** the client is happy to have them custom-built instead of using a form SaaS.
- **Location:** EU hosting is preferred (GDPR, Croatian market).
- **Stack:** React-compatible, because the installed skills (`react-patterns`, `motion-*`, `frontend-a11y`, `react-testing`) are React-based.

## Still to research (phase 1)

- **Transactional email API:** free tier, EU region, SPF/DKIM support. Used for the team notification and the client confirmation.
- **Mailboxes for `@codraft.hr`:** cost per user, EU hosting.
- **Analytics:**
  - self-hosted Umami or Plausible CE (on a VPS)
  - Cloudflare Web Analytics
  - or no analytics at launch

  Analytics always loads after consent (see [compliance.md](../compliance.md)).
- **Booking:** Cal.com (cloud or EU) vs alternatives. It must embed on click, prefill name and email, and support Croatian.
- **Uptime monitoring and backups** (especially for a VPS).
- **An EU static host for comparison**, e.g. Bunny.net.
- **The Anthropic API**: how it handles data, for the phase 4 chatbot. Load the `claude-api` skill first.

## Options to put in front of the architect

1. **Static-first build with React islands on a small Hetzner VPS.** Caddy, a small Node API for forms and the chatbot, self-hosted analytics. All in the EU, fixed cost, more operations work.
2. **The same build on Cloudflare's free tier**, with a Worker for the API. About €0, no server to maintain, but a US provider.
3. **A Next.js server on Hetzner.** The most flexible option, and the most operations work.

For each option the brief asks for:
- the monthly cost including 25 % VAT and IPv4
- the operations burden: patching, backups, monitoring
- how easily the site could move to another host

The architect returns 2–3 options with one recommendation. **The client chooses.**

## Notes

- **No self-run mail server.** Deliverability is poor and the ports are blocked. Send through an email API, with SPF, DKIM and DMARC on the domain (phase 7).
- **Hosting is also a showcase.** If Codraft hosts its own site the way it would host a client's, that supports the "Hosting & Maintenance" offer.
