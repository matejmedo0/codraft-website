# Hosting and services research (2026-10-19)

> **Phase 1 input, not a decision.** This note supersedes [2026-10-18-hosting.md](2026-10-18-hosting.md). It resolves that note's "to verify" and "still to research" lists and feeds the architecture brief. Decisions are recorded as ADR 0008 and later.
>
> **How it was collected.** Five research agents worked in parallel on official vendor pages, docs, terms, changelogs, the npm registry and GitHub. The main session researched the Anthropic API itself (after loading the `claude-api` skill) and re-checked the decision-critical facts; those rows are marked ✓.
>
> **Conventions**
> - Checked on 2026-10-19 unless a row says otherwise.
> - Prices exclude VAT unless stated. Croatian VAT is 25 %.
> - USD prices are converted at the ECB reference rate of 1 EUR = 1.1253 USD (2026-10-16), so $1 ≈ €0.89 and $5 ≈ €4.44.
> - Confidence: **High** = read on the official page or official data today; **Medium** = official but ambiguous or dated, or a reputable secondary source; **Low** = third party only or unverified.

### What changes the plan

1. **The cheap Hetzner servers can't be ordered today.** A VPS option needs a fallback; the closest EU match is OVHcloud VPS-1 at €4.49/month with IPv4 and a daily backup included. ✓
2. **Cal.com fails two booking requirements:** no Croatian booking UI, and no EU hosting after 2026-11-01. Only self-hosted Easy!Appointments offers Croatian UI with EU data.
3. **Cloudflare's own email sending needs Workers Paid** ($5/month) and is in beta. On Cloudflare Free, form emails need an external email API. ✓
4. **A strict CSP works with static pages in Astro, not in Next.js.** Astro's CSP is stable and hash-based. In Next.js a strict CSP needs nonces, which makes every page dynamic.
5. **In Croatia, analytics needs consent even when it is cookieless** (ZEK čl. 43. st. 4., AZOP, EDPB Guidelines 2/2023).
6. **Tooling versions:** TypeScript 7 is now `latest` on npm, but Astro's tooling and typescript-eslint need TypeScript 6. Dependabot supports npm up to v11 and pnpm up to v10.

## 16. What this means for the architecture brief

Claude's reading of the facts above, not facts in themselves.

- **Framework.** For about 11 mostly static pages with a strict CSP and a small JS budget, Astro with React islands fits; Next.js works against both requirements (13.2, 13.3, 13.5).
- **VPS.** Price a VPS option on OVHcloud VPS-1 (€4.49/month, about €5.61 with 25 % VAT, IPv4 and daily backup included). Hetzner CX23 (€5.99 with IPv4, about €7.49 with VAT) only if an order actually goes through.
- **Cloudflare.** Hosting and the form API fit the Free plan at €0. Email needs an external EU email API (section 4) or Workers Paid. The data processor is a US company (DPA, SCCs, DPF); D1 can be pinned to the EU at creation.
- **Booking.** Croatian UI with EU data means self-hosted Easy!Appointments (PHP and MySQL), which fits a VPS but not Cloudflare. NeetoCal gives Croatian UI with US hosting. Cal.com gives neither. The client chooses.
- **Analytics.** Consent is required anyway. The cheapest EU options are GoatCounter (hosted free, or self-hosted with SQLite) and Search Console plus Bing Webmaster Tools without any script.
- **Operations at €0:** UptimeRobot for uptime, Healthchecks.io for backup jobs, Backblaze B2 EU or a Storage Box for off-site copies.
- **Email.** An EU sender with a permanent free tier costs about €0 at this volume: Scaleway (Paris), AhaSend (Amsterdam) or Mailjet (France). Every submission mails an address the visitor typed, so the forms need a honeypot, rate limiting and a short, link-free confirmation, or the sending account can be suspended for abuse.
- **Mailboxes.** €0 only with Zoho Mail Free (web and mobile, up to 5 users). Otherwise Zoho Mail Lite at €0.90/user/month, or Exchange Online Plan 1 at €3.50/user/month with a free shared `info@`.
- **Domain.** Free through CARNET if the registered company name contains "Codraft"; otherwise about €50–99 a year excl. PDV. The name was free on 2026-10-19.
- **Tooling.** Node 24 LTS now (26 from 2026-10-28), TypeScript 6.0.x pinned, npm 11 (or pnpm 10) so Dependabot can update the lockfile.
